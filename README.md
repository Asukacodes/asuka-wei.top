# Personal Site Starter

This folder contains a simple static personal website starter.

## Files

- `index.html`: main page structure and content
- `style.css`: styles and responsive layout
- `script.js`: theme toggle and footer year

## Local Preview

Open `index.html` in browser directly, or run a simple static server.

## Deploy (Vercel example)

1. Create a new GitHub repo and upload this folder.
2. Import the repo in Vercel.
3. Build settings:
   - Framework preset: `Other`
   - Build command: leave empty
   - Output directory: leave empty (root)
4. Deploy.
5. In Vercel dashboard, add your custom domain and follow DNS instructions.

## Customize Checklist

- Replace title and hero text in `index.html`
- Update project cards and links
- Change contact email
- Optionally add your avatar and favicon
